# 🍕 Pizza Sales Dashboard

An interactive Data Analysis Dashboard built in Microsoft Excel to track revenue, order volume, hourly peak trends, size preferences, and top-performing menu items for a pizza restaurant.

## 🛠️ Tools & Features Used
* **Microsoft Excel:** Pivot Tables, Pivot Charts, Custom Color Formatting.
* **Interactive Slicers:** Dynamic filtering by `Pizza Size`, `Pizza Category`, and `Order Date`.
